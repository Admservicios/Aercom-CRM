Aercom CRM en esta PC

Versión local de escritorio — 28 de octubre de 2026.

  1. Extraé el ZIP completo antes de usarlo.
  2. Se necesita Python 3.10 o posterior y Chrome o Edge. No se instala nada automáticamente.
  3. Abrí INICIAR_CRM.cmd desde la carpeta extraída. Dejá abierta la ventana del servidor.
  4. Usá siempre http://127.0.0.1:8000/ en el mismo navegador y perfil. No abras index.html directamente.
  5. En el CRM anterior, descargá y verificá un JSON actualizado. En esta copia, elegí Importar JSON. Comprobá cantidades y algunas fichas; cerrá y reabrí para confirmar que los datos siguen.
  6. Usá Exportar respaldo JSON al terminar la jornada. Comprobá el archivo y guardá copias con fecha fuera del navegador.
El ZIP contiene el programa, no tus datos. Usá una sola pestaña para editar. Borrar los datos del navegador o perder el perfil puede eliminar la información si no conservás respaldos.

Gráficos, Excel y reportes usan bibliotecas incluidas; no necesitan CDN ni Drive. El servidor no publica el CRM en la red ni guarda una base de datos en esta carpeta.

El detalle está en GUIA_LOCAL.md. La variante móvil y el trabajo simultáneo entre pestañas no están incluidos en esta preparación.
